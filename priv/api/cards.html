읽은 카드

불러오는 중입니다.

요청 모델 aethrion-auto로 플레이한 카드를 처음 읽었을 때 모델이 잡은 내용입니다. 상태창의 시작·끝 글자와 카드에 적힌 계산(규칙)이 맞는지 확인하고, 다르면 여기서 고칩니다. 고친 내용은 다음 턴부터 적용됩니다.

규칙을 적는 법 
한 줄에 규칙 하나. 칸 이름은 상태창에 나오는 그대로 적습니다.

항상 성립하는 것      HP.max = Vigor * 10
                      EXP.max = floor(100 * 1.15 ^ (Level - 1))
수치의 범위           Trust = clamp(Trust, 0, 100)
한 턴에 움직이는 폭   Trust = clamp(Trust, Trust.before - 2, Trust.before + 2)
일어나는 일           when EXP >= EXP.max: Level += 1; EXP -= EXP.max
1 오를 때마다         when Level rises: Stat Point += if(Level % 5 == 0, 15, 5)

Field.max는 "30 / 48" 같은 쌍의 뒤쪽 숫자, Field.before는 이번 턴 전의 값입니다.
쓸 수 있는 것: 숫자, 칸 이름, + - * / ^ %, 비교(>= <= > < == !=), and, or,
floor, ceil, round, min, max, clamp(x, 최소, 최대), if(조건, 참, 거짓).
상태창에 없는 칸을 가리키거나 읽을 수 없는 줄은 쓰이지 않습니다.
