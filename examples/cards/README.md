# Example cards

Character cards to try the request model `aethrion-auto` with, written for this repository and released under CC0 1.0: use, change, and share them freely.

- `moonlit-tower.ko.json` (달빛 탑): a solo tower-climbing RPG in Korean whose model prints a status window with every reply, and which states the arithmetic of its numbers (a maximum per stat point, the experience a level takes, points for a level). Import it into RisuAI or SillyTavern, set the request model to `aethrion-auto`, and the window is kept by the rules from the second reply on ([guide](../../docs/risuai.md#keep-the-card-you-already-use)). `/cards` on the server shows the rules read from it.
