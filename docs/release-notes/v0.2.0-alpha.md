# Aethrion v0.2.0-alpha

## The social layer release

v0.1 proved that a character's state can change through explicit rules. v0.2 makes the *social* part real: characters notice each other, confide, spread news, and comfort one another, and every one of those changes can be explained, tested, and phrased by an LLM without the LLM deciding any of it.

> LLMs generate expression; deterministic rules drive the simulation.

## Highlights

**Two host events, four events of story.** The host sends a gift and two hours of time. Rules do the rest:

```txt
e1 user gives Mina a flower (seen by Yuna)
e2 time passes +2h
   Yuna -> user: "You looked happy with Mina earlier. I wondered if you forgot about me."
   e3 Yuna confides in Haru                     (caused by e2)
      Haru -> user: "Yuna told me you gave Mina a flower. Smooth."
      e4 Haru comforts Yuna                      (caused by e3)
```

**Explainable by construction.** Every change is a trace entry naming the rule and event. `why yuna` in the interactive demo prints them.

**A real but powerless LLM.** Anthropic and OpenAI-compatible adapters phrase lines from read-only snapshots and can propose what free text means, from a closed set. Failures fall back to deterministic text. In a supervised world, rendering runs in isolated tasks with timeouts, so the simulation never waits on a model.

**Scenarios you can read.** JSON files with a world, a script, and expectations. They run in CI and render as HTML reports.

## Try it

```bash
mix deps.get
mix test
mix demo.drama
mix demo.interactive
mix aethrion.scenario --all
mix aethrion.report priv/scenarios/01_the_flower.json
```

With a model:

```bash
export ANTHROPIC_API_KEY=...
mix demo.interactive --llm anthropic
```
