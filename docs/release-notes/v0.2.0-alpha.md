# Aethrion v0.2.0-alpha

## The social layer release

v0.1 proved that a character's state can change through explicit rules. v0.2 makes the *social* part real: characters notice each other, confide, spread news, comfort one another, keep each other company, and remember patterns long after the details fade. Every one of those changes can be explained and tested, and an LLM can phrase them without deciding any of them.

> LLMs generate expression; deterministic rules drive the simulation.

## Highlights

**Two host events, four events of story.** The host sends a gift and two hours of time. Rules do the rest:

```txt
e1 user gives Mina a flower (seen by Yuna)
e2 time passes +2h
   Yuna -> user: "You looked happy with Mina earlier. I wondered if you forgot about me."
   e3 Yuna confides in Haru                     (caused by e2)
      Haru -> user: "Yuna told me you gave Mina a flower. Smooth."
      e4 Haru comforts Yuna                      (caused by e3)
```

**Explainable by construction.** Every change is a trace entry naming the rule and event. `why yuna jealousy` prints each change and the chain of events behind it.

**History matters.** Faded conversations consolidate into impressions ("user has been warm to mina 3 times."), and a friend with a record of kindness takes a harsh word at half strength. Tension eases with apologies, comfort, and time.

**Reputation travels.** Snap at Mina in front of Haru and Haru trusts you less; Mina tells Yuna, and Yuna does too, a little. Be warm to Haru the next day and the reply is "Thanks... but I saw what you said to Mina." Once the details fade, a reputation remains.

**A real but powerless LLM.** Anthropic and OpenAI-compatible adapters phrase lines from read-only snapshots and can propose what free text means, from a closed set. Failures fall back to deterministic text, available in English and Korean. In a supervised world, rendering runs in isolated tasks with timeouts, so the simulation never waits on a model.

**Worlds you can replay.** Journals store a world as its starting state plus every host event; replay rebuilds it exactly, and compaction keeps long-running journals fast to start. Scenarios are JSON with expectations and what-if branches; they run in CI and render as HTML reports.

**Tunable without code.** Every rule number is a parameter a world or scenario can override: the bundled small-town scenario runs the rumor rules with different tuning, and news travels one hop further than in the rumor-mill scenario.

## Try it

```bash
mix deps.get
mix test
mix demo.drama
mix demo.branches
mix demo.interactive            # try: why yuna jealousy
mix aethrion.scenario --all
mix aethrion.report priv/scenarios/07_crossroads.json
```

With a model:

```bash
export ANTHROPIC_API_KEY=...
mix demo.interactive --llm anthropic
```

Start with the [tutorial](../tutorial.md) ([한국어](../tutorial.ko.md)).
